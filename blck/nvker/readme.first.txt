come usare il nvker di blcklarp

capitolo 1
1.1 prendere una vpn e attivarla (ex: proton vpn)
1.2 andare sul developer portal di discord, creare un app e copiare il token
1.3 incollarlo nel file nvke.py
1.4 far partire il file

capitolo 2
2.1 aggiungere il bot (col link preso nel dev portal)
2.2 eseguire il comando ,x nel server dove il bot è aggiunto SOLO per nukkare
2.3 eseguire il comando ,banall nel server dove il bot è aggiunto SOLO per bannare tutti gli utenti
2.4 eseguire il comando ,whs {webhook link} {messaggio} nel server dove il bot è aggiunto SOLO per spammare i webhook
